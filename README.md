# なぜ個人ブログ？
記事投稿プラットフォームに比べて、様々な利点があると思ったからです。
- プラットフォームの流行に左右されない
- 自身の発信のみ集約でき、個人の成長を可視化しやすい
- 他者によるいいね数やコメントを気にせず、学んだことを最も発信しやすい形でアウトプットできる
- サイトのレイアウトや機能を自分好みにカスタマイズできる
- データはリポジトリとローカルで管理するので、Githubと個人PCでデータロスが同時に起きない限り紛失しない
- その気になれば独自ドメイン取得やサイト引っ越しも容易

#　デメリット
デメリットももちろんあります。これらを考慮したうえで、Qiita, zennなどと投稿を使い分けることで、活用を最大化できるかと思います。
- インプレッションは外部プラットフォームに比べて稼ぎにくい
 SEO対策やおすすめ機能などがないので、外部プラットフォームよりも見られにくいという明確な欠点はあります。
 他人に読んでもらいたい価値ある情報などはQiitaやzennにも投稿するなど、使い分ける運用が望ましいです。
- 外部からの指摘がしずらいので、誤りなどを訂正しにくい。
 コメント機能などを設ければこのデメリットは払拭可能ですが、外部を気にせずアウトプットしやすいというのが個人ブログのメリットでもあるので、そこはトレードオフになります。
 致命的な誤情報による扇動だけは避けたいので、もしも用にメールアドレスのみ公開しています。
